# Design reference

`stitch-mockup-reference.html` is a Google Stitch–generated visual mockup used as
a design reference for SentinelReg's color palette, typography, and component
shapes (sidebar, header banner, badges, tables).

It is **not part of the running application** — it's a static Tailwind
prototype of a single screen with placeholder content (fictional bank name,
persona, and account numbers, and product claims that don't reflect this
project's actual architecture). The real design system derived from it is
implemented in `app/main.py`'s CSS block and applied across all three
Streamlit pages with SentinelReg's actual data and capabilities.
